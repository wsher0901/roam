## Goal

`docs/ATLAS.md` is born — the system spine: the workshop depicted
as six mermaid diagrams on one page, one-line caption each,
composed FROM the living docs at HEAD, never from memory. Its
posture is the board's: IT RENDERS, ORIGINATES NOTHING — stamped
with its date, least-authoritative, the prose governs; every box
links to the [HOME](../../HOME.md)/skill section that owns the
doctrine, so a currency audit verifies it mechanically.

## Out of scope

- Any new doctrine — a diagram that cannot cite a prose home does
  not ship.
- More than ONE new [HOME](../../HOME.md) routing-table line
  (system map → ATLAS).
- The chronicle layer (bench 3).
- Restyling any existing diagram elsewhere (the board's stage map
  stays the board's).

## Plan

1. Bench birth: branch, this spec, memory stub, draft PR.
2. Read the living docs at HEAD (LAWS · HOME · the ritual and
   lane skills) and compose the six diagrams from them:
   1. The task loop — bench-first birth → work/heartbeat → THE
      GATE → the atomic weld, with the memory→record/history move
      and the ROADMAP tick drawn inside the weld.
   2. The file flow — what a session reads at start (hook → board
      → LAWS → memory) and what each ritual writes where.
   3. Away & return — the chooser completed with the return half:
      liftoff → cockpit → land (retire | pause-and-transfer, the
      fence) → pickup.
   4. A lane's life — bench → label → canary claim → airborne ack
      → work → wake-lock → review → merge.
   5. The surfaces — tower · cockpit · lanes · Web · Design; who
      may write what.
   6. State surfaces — where status is READ from (git · checkbox
      · memory Status) and the board rendering it.
3. Mint the D-number: ATLAS born, the renders-originates-nothing
   posture.
4. [HOME](../../HOME.md) gains one routing-table line.
5. Verification loop, full CI mirror, Actions green, ship §6
   critic, gate report.
