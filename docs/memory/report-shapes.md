## The story

Born 2026-07-30 at the work PC, cashing the top open line of the
inbox the last bench rewrote — the first idea to be picked up
under the entry contract, and it read as one line because that
bench split it.

The sitting's pattern holds: every bench since
[the box-master class](../record/history/workshop/definition/box-masters.md)
has asked the same question of a different file — what is this FOR,
and what does that exclude? SETUP was a container; the charter
carried a procedure; IDEAS bundled ideas. The reports are the same
disease at the speaking surface: six shapes for one job, and a
board that had grown a sitting narrative, essay-length ledger rows
and review receipts that belong in the record.

### THE STANDING DUTY — one real gap, and it was ship's

The rule was that content the new shapes drop must be verified
ORIGIN-BOUND by the ritual's own steps, and anything the ritual
does not already write gets a writing step rather than silently
vanishing. Checked ritual by ritual:

- **pickup's WHAT HAPPENED** — rebuilt from the main task's memory
  Story plus the handoff note. Origin-bound by construction;
  nothing owed.
- **handoff's and liftoff's sitting narrative** — the memories and
  the board already carry it; the new shape keeps one to three
  sentences and points. Nothing owed.
- **land's fleet detail** — each lane's fence carries its own
  progress and exact next step, and the board's fleet-at-ground
  table renders them. Nothing owed.
- **ship's CRITIC VERDICT — OWED.** The old §6 rode the verdict
  "verbatim alongside the summary", which means it lived in the
  message and nowhere else. The new gate report states a FINDING
  COUNT and points — so under push-first the findings must already
  be on origin, and nothing in ship wrote them there. §6 GAINS A
  WRITING STEP: write the critic round into the memory and push,
  BEFORE the gate report. A verdict that lives only in the session
  is one the founder cannot re-read and the external review cannot
  check.

That last one is the bench justifying its own rule: push-first did
not merely restyle a report, it exposed a fact the workshop had
been carrying in conversation at every gate since the critic went
live.
