## What this task is

[ATLAS](../ATLAS.md)'s node labels carry sentences, so its diagrams
render wider than a screen and the page cannot be read as a shape.
This bench writes the fix down as a law in ATLAS's own header —
top-down only, and a node label is a NAME never a sentence — brings
all seven existing diagrams under it, and closes two coverage gaps:
diagram 1 gains the work-intake band (voiced → IDEAS → decide →
ROADMAP → bench) and a new §8 draws a sitting end to end. Contract:
[the spec](../record/specs/atlas-clean.md).
