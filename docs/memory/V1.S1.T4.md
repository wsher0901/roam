## Decisions and dead ends

**2026-09-15 · the bench was re-cut before it was worked.**
[D-088](../record/DECISIONS.md#d-088--product-the-september-re-tailoring--retrieval-the-optimizer-cost-trend-state)
landed while this bench sat unworked. It adds two slots
([FE-15](../data/FACTS.md#f-fe-15--money-saving-tips-),
[FE-16](../data/FACTS.md#f-fe-16--dress-code--conduct-norms-)), makes
the retrieval-policy row mandatory (ruling 3), and puts the Google
Maps verdict on this bench (ruling 17). Both duties went into
[the spec](../record/specs/feasibility.md) as their own sections and
as Done-means lines, and the slot list was WALKED FROM
[the assignment map](../data/FACTS.md#t2t6-assignment-map) rather
than copied from the spec's own stale "14".

**Dead end: REST Countries.** The obvious source for
[FE-01](../data/FACTS.md#f-fe-01--destination-registry)'s
practicalities half. `restcountries.com/v3.1` now answers HTTP 200
with `"This API version has been deprecated"` — a live 200 carrying a
dead payload, which is worse than a 404 because a naive spike would
call it green. Replaced by **Wikidata Query Service** (CC0, one SPARQL
call answers currency, languages, driving side and plug types for
every ISO code at once).

**Dead end: exchangerate.host.** Proposed in the kickoff. It is now
key-gated — HTTP 200 with `missing_access_key`. Same shape of trap.
[FE-14](../data/FACTS.md#f-fe-14--currency-exchange-rates) goes
straight to the ECB reference feed instead, which is the publisher
the resellers all wrap.

**Dead end: the OSRM demo server's profiles.** `router.project-osrm.org`
accepts `/route/v1/walking` and `/route/v1/cycling` and returns
BYTE-IDENTICAL numbers to `/driving` — the public instance carries the
car profile only and silently ignores the path segment. A spike that
had only checked HTTP 200 would have graded a walking-time source A
on car times. Valhalla (FOSSGIS) differentiates correctly — auto
59.6 min / pedestrian 89.8 min / bicycle 35.9 min on the same four Rome
stops — so
[FE-06](../data/FACTS.md#f-fe-06--travel-times--distances-per-mode)
takes Valhalla, with OSRM kept for the car-only matrix.

**Decision: Google Maps is REJECTED for the asset layer.** The
deciding clause is Service Specific Terms 10.3.1 — the customer will
not "attempt to extract or otherwise separate Google Maps Content from
the Grounded Output" — which is precisely what
[D-015](../record/DECISIONS.md#d-015--data-asset-law)'s bitemporal
store does. Full reasoning and the verbatim clauses are in the entry
and in `scripts/spikes/feasibility-maps-grounding.mjs`, which re-greps
them from the primary source on every run so the verdict cannot drift
from its evidence.

**2026-09-15 · what the coverage spikes actually found.** The four
load-bearing slots were spiked in depth and the numbers are worse than
the plan assumed, which is the useful part:

- **[FE-04](../data/FACTS.md#f-fe-04--opening-hours) opening hours —
  31.4%** of 12,627 venues across five city centres carry an
  `opening_hours` tag, spread 18.4% (Bangkok) to 50.4% (Reykjavik),
  with `attraction` the worst category everywhere at 18.9%. FE-04 is a
  HARD GATE, so retrieval is half its working path rather than a
  fallback. The two non-European cities are the two worst covered,
  which runs against where the demo wants to go.
- **[FE-09](../data/FACTS.md#f-fe-09--venue-attributes) venue
  attributes — OSM does not model this fact.** `min_age`,
  `duration` and any adult-audience tag returned 0 of 2,535; `dog` and
  `kids_area` returned 3 and 2. The result IS the zeros: these fields
  are estimates and must render as estimates.
- **[FE-08](../data/FACTS.md#f-fe-08--reservation--timed-entry--permit-flags-)
  reservation — 1.1%** (31 of 2,808), and OSM has no tag at all for
  lead time or sellout speed. The absence rule is written into the
  entry: an untagged venue is never "no booking needed".
- **[FE-05](../data/FACTS.md#f-fe-05--seasonal-closures--operating-seasons-)
  seasonal — 1.5%** month-range coverage on Iceland, the country where
  seasonality most decides a trip. Where tagged the values are
  excellent (a five-band year for the Blue Lagoon, "closed Sep 16–May
  14" for a museum), which is why the slot is B-where-tagged rather
  than written off.

**A gap in our own plan, found by a spike.**
[FE-12](../data/FACTS.md#f-fe-12--area-profiles-) says
"centroid/polygon" and its `best_for[]` derivation assumes the polygon
— but all 113 Rome areas came back as NODES and the
`admin_level=9|10` relations returned nothing. So point-in-polygon is
not available on this data, and
[V1.S3](../ROADMAP.md#v1s3--engine-core--two-families-deep) must
choose a centroid radius or a polygon source. Also worth carrying
forward: `admin_level` numbering is country-specific, so no production
query can hard-code it.

**The retrieval path was probed, and it fails more than it
succeeds** — 2 of 4 allowed-domain targets reachable, 1 of 4 quotable.
A plausible operator URL 404'd and a city tourism site 403'd a scripted
request. [V1.S3.T8](../ROADMAP.md#v1s3--engine-core--two-families-deep)
therefore needs a SEARCH step and a browser-grade fetcher, not a bare
`fetch`; that is recorded as the blocking dependency for FE-15/FE-16.
The one correct DISCARD is worth as much as the one success: vatican.va
redirected and served 8k characters with no dress-code span, and the
policy dropped the value instead of inventing a covering rule.

**Deviation: `npm run build` was NOT run locally.** It is the last
command in [ship §1](../skills/ship.md#1--preflight)'s CI mirror, and
it cannot run from a worktree. Confirmed here rather than taken on
report: it fails with `Error: Could not find the Next.js package
(next/package.json)`, resolved from the worktree root. The four
worktrees share one install in the parent clone, so each has an empty
`node_modules/`; Node resolves the dev tools upward but Turbopack
refuses to resolve above its detected workspace root, and says so —
*"files outside of the workspace root are not compiled"*. It is an
artifact of running four benches off one install, not a defect in this
diff, and the fix is NOT to `npm install` inside the worktree — that
would add a large untracked tree to a lane branch.
**The arbiter covers it.** `.github/workflows/ci.yml` runs
`npm run build` after `npm ci` from a clean checkout, and the pushed
head `3bc8404`'s Actions run was green, so the command this bench
could not run locally DID run against this exact diff
([D-038](../record/DECISIONS.md#d-038--ci-is-the-arbiter) — CI is the
arbiter, and local green never sufficed anyway). Every other mirror
command was run from the worktree and passed.

**Contract change: `scripts/spikes/_overpass.mjs`.** The spec's
file-scope line allowed `scripts/spikes/feasibility-*` and nothing
else. Nine of this bench's spikes query Overpass, and the public
endpoint rate-limits hard enough that retry, mirror rotation and a
client-side timeout are not optional — copied nine times they would
have drifted, and in fact the first two copies already differed. So a
zero-dependency shared helper was added and the spec's Done-means was
amended to name it. It stays lane-disjoint: no sibling bench touches
`scripts/spikes/_overpass.mjs`, so the no-shared-file rule is intact.

**Gotcha, and it cost this bench about an hour.** `fetch` has NO
default timeout, so an Overpass mirror that accepts a connection and
never answers hangs the spike forever — the route-services run sat
silent until it was killed. `_overpass.mjs` now passes
`AbortSignal.timeout(150000)`. The sibling gotcha: node buffers stdout
when it is redirected, and `| tail` shows nothing until the stream
ends, so a long background run looks dead when it is fine. Write to a
log and read the log.

**Critic round on my own diff, before the ready-flip.** Six findings,
all mine, all fixed:
1. Five "alternatives rejected" lines (Mapbox, TripAdvisor, Yelp,
   Foursquare, Numbeo, Expedia) ASSERTED licence terms this bench never
   read. A plausible prior is not a vetting. Each now states what was
   verified and names what was not.
2. A structural audit of every entry against the shipped weather
   entries found five field labels hidden inside bold spans, so a
   copying task grepping for `- Grade:` would have missed them.
   Normalised.
3. The Google Maps verdict was a prose section without the standard
   spine; a verdict is a vetting, so it now carries every field.
4. A forward reference to `#venue-attributes` was committed before that
   section existed — caught by `check:links`, fixed by the next commit.
5. The Eurostat result in the cost-basis spike came back as a flat
   baseline of 100 for 39 countries; reporting that as a working source
   would have been a parse artifact dressed as data. Recorded as
   reachable-but-unproven instead.
6. The slot list was walked from
   [the assignment map](../data/FACTS.md#t2t6-assignment-map) — 16
   facts, 16 slots, one each — rather than trusting the spec's stale
   "14 of them".
