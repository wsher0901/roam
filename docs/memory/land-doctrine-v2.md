assumed every landing begins with the founder saying "land"; the
founder's model says only one of the three does.

### The one place the mandate ran past the evidence

The mandate said clause 3 "closes the parked superseded-seat
line — close it in IDEAS citing this decide." Reading the line
before writing the closure showed it does not quite: its case is
a superseded CONTROL TOWER (a ground seat) LEADING A TEAM, whose
findings would die because supersession is the one road out that
runs no ritual. D-061's tombstone wake-rule is written for the
COCKPIT, and a cockpit never leads a team — that is policy, not a
platform limit
([land §Teams](../skills/land.md#teams--not-this-rituals-case-both-modes)).
So the decide genuinely closes the supersession road for the seat
it names, and leaves the team-findings gap exactly where it was:
a ground tower's supersession still reads "push, write nothing"
in [LAWS](../LAWS.md#parallel-lanes--cloud).

The line was therefore marked PARTLY CLOSED rather than closed —
which [IDEAS](../IDEAS.md)' own header rule already provides for
("a partly-closed entry stays whole") — citing D-061 for what it
settles and naming what survives. Writing a full close would have
recorded a fix that does not exist. Raised for the founder at THE
GATE: generalizing the wake-rule to ANY superseded seat would
close it properly, and that is a LAWS amendment, not a sweep.

### A judgment call inside the recut

The founder's model gives trigger 2 (desk takeover) a cockpit
that "self-retires by the full ritual". Written literally into
the trigger table, that first read as MODE R — but a desk can
take the decision queue while lanes are still airborne, and MODE
R assumes an empty fleet. So trigger 2 routes through
[§0](../skills/land.md#0--derive-the-fleet-route-the-mode) like
any other landing and lands in whichever mode the fleet dictates:
still-flying lanes get FENCED, and the desk resumes them through
[pickup §6](../skills/pickup.md#6--fleet-resume-on-the-founders-answer)
as an ordinary grounded fleet. That keeps "the full ritual"
literally true and makes the handover coherent in the case the
mandate did not spell out.
