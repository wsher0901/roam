### The decision that shaped every entry

The family's honest answer is mostly NOT a feed. Vetting confirmed
what [FACTS](../data/FACTS.md) already suspected with its double-warning
marks: there is no free, licensable, global source of flight routes or
schedules. Every candidate answered HTTP 401. The only free bulk
route dataset — OpenFlights `routes.dat` — was last modified
**2017-02-02**, 9.6 years ago, and still flies 798 Air Berlin, 210
Monarch and 268 Flybe routes. A dataset that flies dead airlines
cannot assert that a route exists, so it was graded as a weak prior
rather than a source.

So the entries were written the other way round from the weather
family: instead of "here is the API and its keys", they say "here is
the ladder rung this fact actually lands on, here is the retrieval
policy that governs it, and here is what it would cost to do better".
$49.99/month, read off aviationstack's own pricing page during the
run, is the number the founder needs.

### The one genuinely clean slot

[TT-04](../data/FACTS.md#f-tt-04--timezone-offset--jet-lag-shift)
grades **A** and needs no vendor at all: the IANA tz database ships
inside Node's ICU (2025c, 418 zones, public domain per IANA's own
LICENSE file, fetched and quoted). The spike proved DST correctness
across a real transition, the 45-minute zones, and agreement with
Open-Meteo on four independent probes. It is the only fact in the
family that is fully, globally, exactly obtainable.

### Dead ends, recorded

- **US CBP airport wait times.** `/api/airports` returns clean JSON
  (66 rows, 46 US IATA codes). The historical series endpoints
  (`/api/waitTime/csv`, `/api/waitTime/excel`) were found by reading
  the site's own JS bundle, but returned the SPA shell rather than
  data for every parameter combination tried. Recorded as LOCATED,
  NOT OBTAINED. It would be US-only regardless, so the global answer
  for `immigration_wait_class` is unchanged.
- **OpenSky Network.** Tempting for
  [TT-02](../data/FACTS.md#f-tt-02--route-existence-) — ADS-B
  observations would show which pairs are actually flown — and it was
  the one endpoint that returned data unauthenticated. Disqualified
  on licence: its terms grant use "solely for the purpose of
  non-profit research and non-profit education" and require a written
  licence for any for-profit use. A
  [D-015](../record/DECISIONS.md#d-015--data-asset-law) disqualifier
  regardless of quality.
- **Transitland.** HTTP 401 unauthenticated. The Mobility Database
  CSV catalogue serves the same discovery need with no key, so
  Transitland was set aside rather than pursued.
- **Carrier pages block robots.** Lufthansa, Schiphol, Japan Airlines
  and British Airways all refused or timed out on a plain automated
  request while Heathrow and Narita answered 200. This is a
  constraint on the retrieval policies themselves, not a footnote:
  [V1.S3.T8](../ROADMAP.md#v1s3--engine-core--two-families-deep) must
  use a real search-and-fetch path, because a policy that assumes
  `fetch()` would fail silently on half its allowed domains.

### The critic round — 5 findings, all applied

Run against the lane's own diff before the ready-flip. Two were
substantive; three were sourcing hygiene.

1. **A coverage claim that was FALSE.** The first local-transit spike
   filtered the Mobility Database on `location.municipality` alone and
   reported "Tokyo and Seoul have ZERO GTFS feeds". Tokyo has **two** —
   Toei Bus and Toei Train, from the Tokyo Metropolitan Bureau of
   Transportation itself, licensed CC BY 4.0. They leave
   `municipality` blank and carry the city in
   `location.subdivision_name`, so the filter read a blank column as
   an absence. The same bug undercounted London (3 to 6), New York
   (16 to 85) and Lisbon (2 to 17). This is the
   [enumeration law](../LAWS.md#knowledge--tracking)'s failure mode
   exactly — an absence taken for a case — and it was caught by the
   critic round, not by the author. The spike now searches four
   fields and prints which one matched; the entry carries the method
   note so the lesson travels with the number. Seoul's and
   Reykjavík's zeros were re-verified and are real: South Korea and
   Iceland have zero catalogue rows of any type.
2. **A grade with no live run behind it.** TT-07 was graded **B**
   "where a GTFS feed exists" on the strength of having FOUND feeds —
   but no feed had been opened, so the claim that feeds carry
   headways was an assumption. The spike now downloads the Toei GTFS
   zip and parses it with a zero-dependency reader: 7.39 MB, 15
   tables, `stop_times.txt` with 1,034,053 rows carrying
   `departure_time` per trip per stop. The B is now proven.
3. **An unsourced licence claim.** The tz entry asserted the IANA
   database is public domain "per its own LICENSE file" without ever
   fetching it. Now fetched and quoted from
   `data.iana.org/time-zones/tzdb/LICENSE`.
4. **A claim whose evidence was not reproducible.** The airports
   entry quotes CDG's municipality string, but the committed spike
   printed only ORY, BVA, NRT, EWR and LGW — the CDG evidence lived
   in a throwaway probe. CDG was added to the spike's named-misses
   list and it was re-run.
5. **Four overreaches, softened to what was actually observed.**
   "the maintained mirror of ourairports.com" (now verified — the
   terms page links to that host directly); "Node 24 currently ships
   2025c" (now: the 24.14.0 build used in the spike); TfL's
   attribution string asserted then hedged (now recorded as an
   unverified lead); and the EU access-point page described as a
   directory when only HTTP 200 had been observed.

A sixth item was checked and cleared: the per-country intercity
counts are a name-match heuristic over provider and feed name, which
the entry now says outright — JP's 0 means no Japanese feed's NAME
looked intercity, not that Japan has no intercity data.
